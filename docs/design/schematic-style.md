# 网页电路原理图规范

网页中的电路原理图使用 `tools/schematic_style.py` 基础配置，以 Schemdraw 的 Matplotlib 后端生成透明背景 SVG。数学标注使用 MathText 的 Computer Modern 字形（LaTeX 风格），导出为矢量路径，避免 SVG 后端将 `$...$` 降级为普通文字。

- 主线与元件轮廓：`#354037`，线宽 `1.35`。
- 电流方向等辅助信息：`#587078`，线宽与主图一致。
- 元件符号、变量和单位：使用 `$...$` 数学语法；本图绘图字号为 `12 pt`，按网页实际显示宽度换算，正文 `16 px` 时图内标注约 `14 px`。
- 背景：透明；不在 SVG 内绘制卡片、边框或阴影。
- SVG 画布只保留少量安全留白（Schemdraw `margin=0.08`），避免图形与正文之间出现大块空白。
- 连接线采用圆角端点和圆角连接；节点只在确有电气连接含义时绘制。
- 图内只保留必要的元件代号、变量和方向，不写解释性长句。
- 网页图注置于图下方，使用“图 章节号.序号　图名。说明”的格式。
- 图题使用正文同色、同字体，字号 `13 px`；编号 Times New Roman，数学变量以 `$...$` 交由 KaTeX 排版。
- 网页中统一使用 `<DocFigure kind="schematic" ... />`。图 1.1 的画布为 `339.372 × 150.348`，显示宽度 `24.75em`（桌面约 `396 px`，高度约 `175 px`），最大宽度不超过正文。图题距图 `8 px`。
- 图 1.1 使用 `python tools/draw-series-rl.py` 重绘，需安装 `schemdraw` 与 `matplotlib`；脚本也支持本地 `tmp/schematic-runtime` 依赖目录。

新增原理图时导入 `configure`、`INK`、`ACCENT` 和 `LINE_WIDTH`，避免在各绘图脚本中重复定义视觉参数。
