# 文库内容写作约定

主文面向第一次建立概念的读者，以科学史、问题动机、物理直觉和工程用途为主线。先讲原有方法遇到什么问题、这个概念解决什么，再给最低限度的表达式。历史事实需引用可核查来源；现代教学类比不得伪装成发明者的真实思路。

性质表、形式化证明、长篇代数推导放到深入阅读或示例页，用描述性链接连接。主文仍需保留防止误解的关键适用条件，不能为了易读而牺牲准确性。算例继续集中在示例栏目。

公式以 Markdown LaTeX 维护。行内公式与正文大小接近，保留源代码并支持复制。独立公式每篇从 (1) 开始编号并提供锚点；文中引用应附页面上下文。连续推导不应挤在概念导读中。

此次先按此规范重写拉普拉斯变换；其余已有章节后续逐章整理，不声称已全站完成内容改写。
