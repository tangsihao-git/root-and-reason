软件中的一次寄存器写入，最终必须转化为硬件可识别的总线事务。理解这条路径有助于区分“程序变量”和“设备寄存器”，也能解释为什么错误的地址、访问宽度或时序会直接改变外设行为。

## 3.3.1 CPU 发起的是总线事务

CPU 执行 Load／Store 指令时，并不是直接连接到某个外设寄存器，而是向片内互连发起一次事务。事务通常包含：

- 地址：本次访问由哪个目标接收；
- 写数据或读数据通道：传输的具体位模式；
- 读写方向、字节选通和访问宽度；
- 有效、就绪、响应及保护属性等控制信息。

可以把写事务抽象为：

```text
Store 指令
    ↓
地址 + 数据 + 写请求 + 字节选通
    ↓
AXI / AHB / APB 等片内互连
    ↓
地址译码与目标选择
    ↓
外设内部寄存器译码
    ↓
寄存器在有效时钟沿更新
```

“地址决定写谁，数据决定写什么，控制信号决定这次访问是否成立”是理解寄存器访问的基本框架。

## 3.3.2 MMIO 与统一地址空间

内存映射 I/O（MMIO）把 RAM、GPIO、SPI 控制器、UART 和定时器等资源安排在 CPU 可寻址空间的不同范围内。例如：

```text
0x0000_0000 ...  RAM
0x4000_0000 ...  GPIO
0x4001_0000 ...  SPI Controller
0x4002_0000 ...  UART
```

地址不是器件的几何位置，而是互连用于路由事务的编号。高位地址常用于选择外设或从端口，低位偏移用于选择该外设内部的具体寄存器。多个寄存器可以共享数据通道，只有地址命中的寄存器获得选通信号：

$$
Q_{next}=\begin{cases}
D,& EN=1,\\
Q,& EN=0.
\end{cases}
$$

因此，大量寄存器不需要各自连接一套 CPU 数据线，而是通过共享总线、地址编码和译码逻辑复用传输资源。

## 3.3.3 Linux 中的 MMIO 访问

裸机示例常把物理地址转换为 `volatile` 指针，但 Linux 内核驱动需要先取得设备资源并建立映射，再使用体系结构提供的 I/O 访问器：

```c
void __iomem *base;

base = devm_ioremap_resource(dev, res);
writel(value, base + REG_OFFSET);
status = readl(base + STATUS_OFFSET);
```

`__iomem` 用于区分设备地址与普通内存地址；`readl()`、`writel()` 等访问器处理特定体系结构下的访问方式、字节序和必要顺序约束。`volatile` 只能限制编译器省略或合并访问，不能替代锁、原子操作、内存屏障或 Linux 的 MMIO API。

一些互连采用 posted write：CPU 看到写指令完成时，写事务仍可能在桥或设备侧排队。需要确认写入已经到达设备时，常按设备手册要求读取相同设备中的安全寄存器完成刷新。

## 3.3.4 寄存器不是普通内存

RAM 写入通常只是保存数据；控制寄存器的某一位却可能连接状态机、复用器、时钟门控、DMA 或输出逻辑。一次写入可能沿着以下链路生效：

```text
控制位 0 → 1
    ↓
触发器或锁存器状态变化
    ↓
状态机 / MUX / Enable 改变
    ↓
GPIO 翻转、SPI 启动、DMA 搬运或中断产生
```

寄存器还可能具有普通内存没有的副作用：写 1 清零（W1C）、读后清零、只写命令、只读状态、自清零启动位或不同访问宽度对应不同语义。驱动必须按参考手册定义访问，不能用普通读—改—写模板处理所有寄存器。

## 3.3.5 SoC 地址与外部器件地址

外部 SPI ADC 的寄存器地址不属于 CPU 的 MMIO 地址空间。CPU 能直接寻址的是 SoC 内部 SPI 控制器；ADC 的寄存器编号需要编码进串行命令：

```text
CPU 的 MMIO 地址
    ↓
SPI Controller 的 TX FIFO / 控制寄存器
    ↓
[命令][ADC 寄存器地址][数据]
    ↓
控制器产生 CS、SCLK、MOSI，并采集 MISO
    ↓
ADC 解析自己的寄存器地址
```

这里存在两个不同的地址域：CPU 用 MMIO 地址选择 SPI 控制器，SPI 协议中的字段再选择 ADC 内部寄存器。把二者混为一谈，会导致设备树、驱动和总线抓包中的地址含义无法对应。

## 3.3.6 完整因果链

一次软件写入可按以下层次追踪：

| 层次 | 观察对象 | 常用验证方法 |
| --- | --- | --- |
| 程序与驱动 | API、偏移、位域和值 | 日志、tracepoint、代码审查 |
| CPU 与虚拟内存 | 指令、页表和 MMIO 映射 | 反汇编、内核资源、异常信息 |
| 片内互连 | 地址、数据、握手与响应 | 片上逻辑分析仪、总线性能计数器 |
| 外设寄存器 | 选通、状态位和 FIFO | 寄存器回读、调试端口 |
| 外部引脚 | GPIO、CS、时钟和数据 | 示波器、逻辑分析仪 |

排查“寄存器已经写入但硬件没有动作”时，应沿这条链逐层确认，而不能只检查 C 代码中的变量值。
