---
title: "4.5 从溯源结果到抑制方案"
description: "依据振荡类型、源区、传播通道和工程约束选择可验证的治理措施。"
---

溯源只有在能改变决策时才有价值。把“哪个测点振幅最大”直接映射为“在哪里加阻尼”往往无效；应根据源、弱阻尼模态、传播通道和执行器能力分别选择措施。

## 4.5.1 先匹配问题类型

| 诊断结果 | 优先措施 | 需要避免的误区 |
| --- | --- | --- |
| 自然模态阻尼不足 | PSS、附加阻尼、运行点／拓扑调整 | 只压低某测点幅值 |
| 明确周期源 | 修复源设备、带限前馈、隔离异常指令 | 只提高系统阻尼而保留外源 |
| 控制—网络相互作用 | 控制带宽协调、阻抗塑形、有源／被动阻尼 | 只按短路比判断 |
| 串补—轴系 SSR | 串补度调整、阻尼控制、保护与旁路 | 忽略轴系疲劳 |
| 多设备耦合 | 参数协调、分组控制、网络增强 | 单机逐一验证替代系统验证 |

## 4.5.2 源端、通道与受扰端

- **源端治理**：修复异常控制、改变带宽、增加正阻尼或限制周期扰动，通常最直接。
- **传播通道治理**：调整拓扑、串补、电缆／滤波器参数，或增加网络阻尼与强度。
- **受扰端治理**：设置陷波、局部阻尼和保护，降低敏感设备响应。

源端不可控或短期无法停运时，可在传播通道或高参与设备上部署临时措施，但要明确它只降低风险而未消除根因。

## 4.5.3 参数优化与多工况校核

设控制参数为 $\boldsymbol p$，可构造多工况目标

$$
J(\boldsymbol p)=
\max_{q\in\mathcal Q}
\left[-\min_{k\in\mathcal K}\zeta_k(\boldsymbol p,q)
+\rho_u\|u\|_2^2+\rho_rR(\boldsymbol p,q)\right],
$$

其中 $q$ 表示工况，$R$ 表示裕度、噪声或约束惩罚。优化结果应与工程可解释的参数范围结合，避免得到对模型误差极敏感的尖锐最优点。

## 4.5.4 检查其他频段与大扰动

任何抑制措施都可能改变其他环路：降低 PLL 带宽可能改善弱网稳定却减慢同步；提高电流环带宽可能压低低频误差却减少高频相位裕度；虚拟阻尼可能增加噪声和电流峰值。应同时检查：

1. 全部小信号模态；
2. 广义奈奎斯特／端口裕度；
3. 谐波与电能质量；
4. 故障穿越、限流和恢复；
5. 热容量、SOC、轴系扭矩和保护配合。

## 4.5.5 运行措施与长期措施

运行期可采用降出力、改变机组组合、调整无功、切换控制模式、旁路串补或退出异常设备。长期措施包括控制重整定、场站级协调、硬件滤波／阻尼、网络增强和保护改造。每项措施要写明触发条件、执行顺序、撤销条件和预期观测变化。

## 4.5.6 分级验证与上线

1. 在统一基准模型上复现原事件。
2. 在线性模型中验证机理、灵敏度和裕度。
3. 在 EMT 中检查时延、限幅和故障场景。
4. 用 CHIL／PHIL 验证真实控制器与接口。
5. 现场先小范围、低增益投运，监测目标和非目标频段。
6. 固化模型版本、参数、回退策略和复测周期。

## 4.5.7 闭环证据

有效治理应同时满足：预测的临界频率或极点按预期移动；量测中的目标频带能量下降；源区方向指标改变；控制器未持续饱和；其他模态和保护裕度未恶化。若只看到幅值下降而机理指标不变，应检查是否只是工况或可观性变化。
