本附录用于维护研究过程，而不是重复正文。每个案例建议建立独立目录，保存原始数据、处理脚本、模型版本、图表和结论记录。

## 5.1.1 数据字典最小字段

| 字段 | 示例 |
| --- | --- |
| 测点与设备 | 场站汇集线 A、机组 3 |
| 物理量与单位 | 三相电流 RMS / A |
| 方向与相序 | 流出场站为正、ABC |
| 采样与报告率 | 12.8 kHz / 100 fps |
| 时钟与质量 | GNSS 锁定、误差上限 |
| 变比与基值 | CT/PT、$S_b$、$V_b$ |
| 滤波与延迟 | 模拟截止频率、数字群时延 |
| 配置版本 | 固件、控制参数、通道映射 |

## 5.1.2 模型清单

每个模型记录：用途与有效频带、工作点、状态和端口、参数来源、是否含限幅／保护、线性化方法、验证数据以及已知偏差。黑盒模型还应记录扫频幅值、注入位置、坐标系和拟合阶次。

## 5.1.3 事件记录模板

1. 事件编号、时间、运行方式和拓扑；
2. 首次告警、结束时间和最大幅值；
3. 主频、阻尼、时频轨迹和影响范围；
4. 数据质量与被排除通道；
5. 候选源、支持与反对证据；
6. 机理模型、关键参数与复现结果；
7. 采取的措施、预期变化和实际结果；
8. 结论等级、遗留问题和后续负责人。

## 5.1.4 仿真与试验记录

保存潮流文件、动态模型、EMT 工程、控制代码哈希和初始化日志。每次扫参写明参数范围、步长和失败条件；每次 CHIL／PHIL 试验写明接口算法、功率放大器带宽、时延和保护设置。

## 5.1.6 维护原则

正文中的频段、阈值和模型假设若随项目更新，应在提交记录中说明来源和适用范围。案例数据若不能公开，可保留脱敏特征、模型参数范围和可复现的合成数据，不要只留下不可核验的图片。
