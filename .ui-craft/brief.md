# Research library — ink edition

Audience: Chinese-speaking power-system researchers. Primary task: reading and understanding.
Approved stack: Next.js, React, shadcn/ui, Tailwind, local Markdown/MDX. Custom navigation, static export. No Fumadocs/Astro in active application.
Homepage: one viewport, one entrance, huge-canopied pen-and-ink tree above short centered Chinese copy, generous whitespace. No feature cards.
Docs: persistent left navigation, central article, right outline. Linear Docs hierarchy adapted to light paper, crisp angular controls and ink rules. No route animations; hover/disclosure only.
Preserve content, URLs, examples, equations, figures, references, LaTeX copy and search. Mobile navigation accessible.
User preferences override default skill choices for rounded corners, shadows and marketing sections. Supplied brief resolves discovery.
